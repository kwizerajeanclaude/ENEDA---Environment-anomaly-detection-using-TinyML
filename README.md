# ENADE---Environment-anomaly-detection-using-TinyML
Design and Implementation of a TinyML-Based Intelligent Wireless Sensor Network for Real-Time Environmental Anomaly Detection
Environmental monitoring systems must detect hazards such as abnormal temperature, gas leakage, air pollution spikes, and humidity variations. Traditional cloud-based monitoring introduces latency, increases bandwidth consumption, and raises privacy concerns.
# Objectives
1. Design a low-power Wireless Sensor Network node with embedded Machine Learning capability.
2. Develop and optimize a lightweight anomaly detection model.
3. Deploy and evaluate the model on resource-constrained hardware for real-time detection.
